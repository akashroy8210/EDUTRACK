# MyDashboard Frontend

Standalone React 19 + Vite 6 + Tailwind CSS v4 client application.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build production bundle
npm run build

# 4. Preview build
npm run preview
```

## Configuration

- `vite.config.ts`: Pure Vite configuration with `@` alias to `./src`.
- `.env`: Configures `VITE_API_URL=http://localhost:5000/api`.
- `index.html`: Standard HTML5 shell with Google Outfit and JetBrains Mono fonts.
